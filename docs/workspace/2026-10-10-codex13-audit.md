# OC Suite codex13 audit

## Changes

- Fixed the native armory category detector. Torn marks a containing `LI`
  with `aria-selected="true"`, before the category anchor in DOM order. The old
  detector stopped at that container's missing `href`, so annotations, category
  navigation and the native loan worklist could fail. Resolve a visible category
  anchor inside the selected container; skip non-category links such as `#nogo`.
- Scope native annotation and worklist mounting to the selected category panel,
  including when Torn retains another category's rows. Cancel superseded work
  and disconnect the old observer on navigation.
- Disable loan/retrieve shortcuts in native snapshots older than five minutes.
  Ask the user to refresh Crimes before preparing an action from that worklist.
- Refresh existing armory activity on the first open in a session. Previously,
  having any saved ledger prevented the initial refresh, however old it was.
- Track mounted Armory, Consumables and War panes by DOM node using WeakSets.
  Replacement panes render after SPA navigation; detached panes are not retained.
- Cancel superseded native Crimes money-badge waiters. A four-navigation fixture
  previously accumulated seven additional intervals; the regression now stays
  within the baseline plus one transient waiter.
- Render OC finance history and native paid/unpaid payout tables in independent
  pages of 50 records. Full inputs still feed totals and exports. Older records
  remain reachable through Previous/Next controls.
- Correct update/download metadata to this GitHub distribution. The old Codex
  metadata pointed to a different Greasy Fork script.
- Repair the development server's source path after repository organization and
  expose the `.user.js` installation route.

## Automated verification

Run from the repository root with Node.js. Browser tests need `puppeteer-core`
and the Brave executable configured in the test. They use synthetic data and
close the exact browsers they launch. They do not submit native game actions.

Install browser dependencies with `npm ci --prefix test/browser`. The fixture
tests use the usual Windows Brave installation path; adjust `executablePath`
in the tests if Brave is installed elsewhere.

```text
node --check Torn_OC_Suite_Codex.user.js
node test/codex-diagnostics.test.js
node test/codex-lifecycle.test.js
node test/consumables-codex.test.js
node test/memory-lifecycle.test.js
node test/loan-endpoint.test.js
node test/codex-pda-storage.test.js
node test/oc-suite-classic-ui.test.js
node test/armory-fetch.test.cjs
node test/armory-snapshot.test.cjs
node test/codex-distribution.test.cjs
node test/finance-pagination.test.cjs
node test/browser/armory-navigation.cjs
node test/browser/oc-suite-remount.cjs
node test/browser/armory-loans.cjs
node test/browser/armory-ui.cjs
node test/browser/war-ui.cjs
node test/browser/consumables-ui.cjs
node test/browser/codex-suite-audit.cjs
```

All commands passed for codex13 on 2026-10-10. The full-source browser fixture
checks all seven tabs, a populated medical loan worklist, 251 completed OCs,
finance pagination, four SPA replacements, bounded interval counts and zero
script page errors. Responsive checks cover 1920x1080, 390x844, 430x932 and
844x390. Synthetic normal startup and first data render took 820 ms in this run;
this is not a measurement of live Torn or flying-state startup.

## Live verification

The signed-in desktop browser confirmed the old native Medical failure:
14 item rows, zero annotations and no worklist card. Read-only DOM inspection
confirmed the selected `LI` was matched before its category anchor. A focused
regression failed with `null` instead of `medical` before the selector fix.

Final installed codex13 live checks are pending. No page captures, API keys,
private chat contents or member records are included in this audit.

## Limits

Flying/abroad startup timing remains an independent investigation. Native Torn
PDA APIs need testing in the actual app; desktop mobile viewports and storage
fixtures cannot establish native WebView behavior. Actual Loan/Retrieve
submission, payouts, backend deployment and game mutations are outside these
checks. Legacy inferred payout rows retain their existing rendering behavior.

The original PurrfectCrime and published Greasy Fork snapshot were preserved.
