# Userscript defaults

Use GPL-3.0 for every new or actively maintained userscript, matching Torn OC Suite Codex. Include the full GPLv3 license in source packages and ZIPs.

Greasy Fork headers must contain exactly one name, namespace, version, description, author and license, plus the real URL scope, run timing, grants and connect domains. Preserve installed namespaces and existing attribution. Builders own generated metadata.

Retain upstream copyright/license notices. Preserve archived originals and published historical snapshots with their recorded metadata.

Never embed API keys, sheet secrets, passwords, tokens or session cookies in source, tests, public documentation or generated artifacts.
